`*.go` files + 180 non-test Go files under `backend/` = **190 files, 53,304 Go lines**
(line counts via `(Get-Content f).Count`).

(auralis-core, auralis-config, auralis-store, auralis-ffmpeg, auralis-tagger,
auralis-providers); all other target crates below are **proposed** and do not exist yet.

Status rules: `done` = every function/method in the Go file has a Rust equivalent with
the same behavior (checked against Rust source). `partial` = some exist; notes list the
MISSING Go functions by name. `missing` = no Rust equivalent. `done` is claimed only
where the Rust source was read and matches.
